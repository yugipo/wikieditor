# 캐릭터 위키 에디터

나무위키 스타일의 캐릭터 문서를 브라우저에서 바로 편집하고, 티스토리 등 블로그에 붙여넣을 HTML이나 이미지로 내보내는 편집기입니다.
설치나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 바로 쓰기

- **GitHub Pages로 열기**: 아래 [배포 방법](#github-pages로-배포하기)대로 설정하면 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.
- **내 컴퓨터에서 열기**: `index.html`을 내려받아 브라우저(크롬·엣지·웨일 등)로 열면 됩니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 문서 구조 | 섹션 추가·삭제, 번호 직접 수정(3.1처럼 쓰면 하위 섹션), 번호 순 자동 목차, 상위 섹션을 닫으면 하위 섹션도 함께 닫힘 |
| 삽입 | 각주(마우스를 올리면 내용 팝업, 클릭하면 이동), 대사 박스, 스포일러 주의문구, 표, 이미지, 링크·# 링크칩 — 모두 커서 위치에 삽입 |
| 서식 | 굵게, 기울임, 글씨 크기, 글씨색, 배경색, 정렬 |
| 표 | 칸 드래그 선택, 행·열 추가/삭제, 행·열 합치기/해제, 칸 배경, 테두리, 너비·높이, 여러 칸 서식 일괄 적용, 칸 안 이미지 |
| 이미지·대사·링크 | 이미지 크기 조절, 대사 박스 배경·컬러칩·테두리, 링크 주소 변경·해제 |
| 편집 | 뒤로가기·앞으로가기(Ctrl+Z / Ctrl+Y), 수정 날짜 자동 갱신(직접 수정 가능) |
| 저장·내보내기 | 자동 저장, 복사(블로그용 HTML), HTML 다운로드, 이미지(PNG)로 저장 |

## 사용 방법

1. 페이지를 열면 편집 모드로 시작합니다. **보기**를 누르면 완성된 모습을 볼 수 있습니다.
2. 본문에서 원하는 위치를 클릭한 뒤 툴바의 **각주 / 대사 / 주의문구 / 표 / 이미지 / 링크** 버튼을 누르면 그 자리에 들어갑니다.
3. 표·이미지·대사 박스·링크를 클릭하면 툴바 아래에 해당 도구가 나타납니다.
4. 섹션 제목이나 블록에 마우스를 올리면 나오는 **✕** 버튼으로 삭제합니다.
5. 프로필 이미지는 편집 모드에서 이미지 칸을 클릭해 올립니다.

### 티스토리에 올리기

1. **복사** 버튼을 누릅니다.
2. 티스토리 글쓰기에서 **기본모드 → HTML** 로 바꾼 뒤 붙여넣습니다.

복사한 HTML에는 화면과 똑같이 보이도록 CSS와 동작 스크립트(섹션 접기, 각주 팝업·이동)가 함께 들어갑니다.
블로그 스킨의 스타일보다 위키 스타일이 우선 적용되도록 만들어져 있습니다.

## 알아두실 점

- **저장 위치**: 작성한 내용은 서버가 아니라 **사용 중인 브라우저 안**에 저장됩니다.
  다른 컴퓨터·다른 브라우저에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 사라집니다.
  보관하려면 **다운로드**(HTML) 또는 **이미지로 저장**으로 파일을 남겨 두세요.
- **이미지**: 이미지는 문서 안에 직접 들어갑니다. 800KB보다 큰 사진은 자동으로 긴 변 1600px로 줄여서 넣습니다.
- **인터넷 연결**: 글꼴(Noto Sans KR), 아이콘, 이미지 저장 기능(html2canvas)은 인터넷에서 불러옵니다.
  인터넷이 없으면 글꼴·아이콘이 기본 모양으로 보이고, 이미지로 저장은 동작하지 않습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `wiki-editor`
2. 저장소 화면에서 **Add file → Upload files** 를 눌러 이 폴더의 파일(`index.html`, `README.md`, `.nojekyll`)을 올리고 **Commit changes** 를 누릅니다.
   - `.nojekyll` 은 이름이 점으로 시작해 탐색기에서 안 보일 수 있습니다. 없어도 동작에는 문제가 없습니다.
3. 저장소의 **Settings → Pages** 로 이동합니다.
4. **Build and deployment** 의 Source를 **Deploy from a branch** 로, Branch를 **main** / **/(root)** 로 고르고 **Save** 를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 나오는 주소(`https://<아이디>.github.io/wiki-editor/`)로 접속합니다.
