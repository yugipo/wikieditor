# 캐릭터 위키 에디터

위키 스타일의 캐릭터 문서를 브라우저에서 바로 편집하고, 티스토리 등 블로그에 붙여넣을 HTML·이미지·워드 파일로 내보내는 편집기입니다.
설치나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 툴바

| 위치 | 버튼 |
|---|---|
| 파일 | 보기/편집 · 불러오기 · 저장 · 코드복사 · 다운로드 · 이미지 저장 · 워드 저장 |
| 삽입 | ↶ ↷(뒤로·앞으로) · 섹션 · 각주 · 대사 · 주의문구 · 접기 · 표 · 이미지 · 링크 |
| 서식 | 굵게 · 기울임 · 밑줄 · 취소선 · 글머리 기호 · 글씨 크기(− 15 +) · 글씨색 · 배경색 · 정렬 |

표·이미지·대사 박스·링크를 클릭하면 툴바 아래에 해당 도구가 나타납니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 문서 구조 | 섹션 추가·삭제, 번호 직접 수정(3.1처럼 쓰면 하위 섹션), 번호 순 자동 목차, 상위 섹션을 닫으면 하위 섹션도 함께 닫힘, 본문이 없는 섹션·본문 끝의 빈 줄은 보기에서 숨김 |
| 본문 입력 | 섹션 본문은 하나의 입력칸 — 문단을 넘나들며 선택·서식 적용, 표가 맨 위·맨 아래에 있어도 ↑/↓ 키나 칸의 빈 곳 클릭으로 그 위·아래에 글쓰기 |
| 삽입 | 각주, 대사 박스, 스포일러 주의문구, 표, 이미지, 링크·# 링크칩·섹션 링크(#3.1), 접기 — 모두 커서 위치에 삽입 |
| 접기 | `[ 펼치기 · 접기 ]` 글씨 직접 수정 · 접기 안에서도 표·이미지·대사 등 모든 삽입 기능 사용 · 표의 칸 안에도 넣기 가능 · **행 단위 접기**: 표의 칸을 여러 개 드래그한 뒤 누르면 그 영역의 행만 접힘(선택 밖 열의 합친 칸은 그대로 유지), 다시 드래그하고 누르면 해제 |
| 서식 | 굵게·기울임·밑줄·취소선, 글머리 기호, 글씨 크기(기본 15px), 글씨색·배경색, 정렬 |
| 색 고르기 | 모든 색 도구가 같은 색 창 사용(PC·모바일). 창 아래 **＋** 칸으로 컬러칩 등록, 길게 누르거나 우클릭하면 삭제 — 칩은 브라우저와 문서에 함께 저장 |
| 표 |  +행·+열·−행·−열, 행·열 합치기/해제, 칸 배경, 테두리, 너비·높이, 비율 고정, 여러 칸 서식 일괄 적용, 칸 안 이미지 |
| 이미지·대사·링크 | 이미지 크기 조절·주소 변경, 대사 박스 배경·컬러칩·테두리, 링크 주소 변경·해제 |
| 편집 | 뒤로가기·앞으로가기(Ctrl+Z / Ctrl+Y), 수정 날짜 자동 갱신(직접 수정 가능) |
| 저장·내보내기 | 자동 저장, 불러오기, 코드복사(블로그용 HTML), HTML 다운로드, 이미지 저장(PNG), 워드 저장(.docx) — 파일 이름 지정 가능 |

## 사용 방법

1. 페이지를 열면 편집 모드로 시작합니다. **보기**를 누르면 완성된 모습을 볼 수 있습니다.
2. 섹션 본문(점선 칸) 안에서 원하는 위치를 클릭한 뒤 툴바의 삽입 버튼을 누르면 그 자리에 들어갑니다.
3. 섹션 제목이나 블록에 마우스를 올리면 나오는 **✕** 버튼으로 삭제합니다.
4. 프로필 이미지는 편집 모드에서 이미지 칸을 클릭해 올립니다.

### 티스토리에 올리기

1. **코드복사** 버튼을 누릅니다.
2. 티스토리 글쓰기에서 **기본모드 → HTML** 로 바꾼 뒤 붙여넣습니다.

코드복사한 HTML에는 화면과 똑같이 보이도록 CSS와 동작 스크립트(섹션 접기, 각주 팝업·이동, 섹션 링크, 행 접기)가 함께 들어가며, 블로그 스킨의 스타일보다 위키 스타일이 우선 적용됩니다. 접기는 닫힌 채로 시작합니다.

### 워드·구글 문서로 저장

**워드 저장**을 누르면 `.docx` 파일이 만들어집니다. 워드에서 바로 열거나, 구글 드라이브에 올린 뒤 **연결 앱 → Google 문서**로 열어 편집할 수 있습니다.
글자 서식·표(칸 합치기·배경색)·이미지·링크·목록은 그대로 옮겨지고, 각주는 본문 [1] ↔ 각주 [1]이 서로 링크(워드 책갈피)로 이어집니다. 목차를 누르면 해당 섹션으로 이동합니다(워드는 Ctrl+클릭).
섹션 접기·접기 상자·각주 팝업처럼 워드에 없는 기능은 펼친 상태의 일반 문서 모양으로 바뀝니다.

### 예전에 만든 문서 이어서 고치기

**불러오기** 버튼을 누르고, **다운로드**로 받은 HTML 파일을 고르거나 **코드복사**한 HTML(티스토리 HTML 편집 화면에서 다시 복사한 내용도 가능)을 붙여넣으면 편집기로 다시 불러옵니다.

## 알아두실 점

- **저장 위치**: 작성한 내용은 서버가 아니라 **사용 중인 브라우저 안**에 저장됩니다.
  다른 컴퓨터·다른 브라우저에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 사라집니다.
  보관하려면 **다운로드**(HTML) 또는 **이미지 저장**으로 파일을 남겨 두세요.
- **이미지**: 이미지를 **주소(URL)** 로 넣으면 HTML에 짧은 주소 한 줄만 들어갑니다.
  **파일**로 넣으면 이미지가 HTML 안에 통째로 들어가 코드가 매우 길어집니다(800KB보다 큰 사진은 긴 변 1600px로 줄여서 넣음). 이미 파일로 넣은 이미지는 클릭 후 **주소 변경**으로 바꿀 수 있습니다.
- **인터넷 연결**: 글꼴(Noto Sans KR), 아이콘, 이미지 저장(html2canvas)·워드 저장(docx) 기능은 인터넷에서 불러옵니다.
  인터넷이 없으면 글꼴·아이콘이 기본 모양으로 보이고, 이미지 저장·워드 저장은 동작하지 않습니다.
- **행 단위 접기**는 표의 행 숨김 기능(`visibility: collapse`)을 사용합니다. 크롬·엣지·파이어폭스에서 동작하며, 오래된 사파리에서는 숨긴 자리가 빈칸으로 남을 수 있습니다.
